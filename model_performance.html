Expected columns (case-insensitive)

client_idRequired. Client identifier.
date or date_tRequired. As-of (scoring) date of the row (YYYY-MM-DD).
y_trueRequired. 1 if the client bought a membership within 14 days after date, else 0.
y_score or score_rawRequired. Model score, 0 to 1. The daily ranking uses it.
score_calOptional. Isotonic-calibrated score: tie-breaker in the ranking, τ threshold in the replay, calibrated tier cutoffs.
purchase_dateOptional. Membership purchase date for positives. Otherwise taken from days_to_conversion, else estimated as last positive date + 1.
in_existing_rulesOptional (0/1). Client already targeted by existing marketing rules; enables the exclusion and tier overlap.
lifecycle_stage, product_group_on_date_t, primary_location_idOptional. Lifecycle filter, tier profiles, per-studio cap.
splitOptional. Enables period comparison (e.g. validation vs. test).
days_to_conversionOptional. Days from date to purchase (positives). Enables the Timing tab.
class_id, coach_idOptional. Enable the Coach Roster simulation.
other columnsText columns with <50 values become segments; numeric columns become features for error analysis. If a required column has another name you can map it after loading.
